Read Along

Privacy Policy

Last updated: 22 October 2026

Read Along is a browser extension that reads web pages aloud. It is designed to work entirely on your device.

This is the public home of the privacy policy for the Read Along browser extension. This website is a static page hosted on GitHub Pages; it does not set cookies or run analytics.

What the extension does with page text

When you start reading, Read Along extracts the visible text of the page you are on, in memory, so it can speak it and highlight the current word. The text is discarded when you stop, navigate away, or close the tab.

  • Page text is never transmitted to us or to any third party.
  • Page text is not stored anywhere.
  • No account is required.

Network requests

The extension makes no network requests. Speech is produced by the speech synthesis voices already installed on your operating system. The extension contains no analytics, telemetry, advertising, or remote code.

Settings

Your reading preferences — speed, chosen voice, and whether the page should scroll along — are saved with chrome.storage.sync. That storage is provided by your browser and may sync between browsers where you are signed in. It contains only those preferences. No page content is included.

Permissions

The extension needs access to the pages you read so it can find the text, paint the spoken word, and scroll the page. It requests the smallest set of permissions that makes that possible:

  • Host access — to read the page when you ask it to.
  • Context menus — to add the “Read this page aloud”, “Read selection aloud”, and “Read from here” items.
  • Storage — to remember your speed, voice, and scroll preference.

Read Along does not modify page content, submit forms, or read passwords.

Data sharing and sale

No data is collected, sold, rented, or shared. No data is used for advertising, profiling, or credit decisions.

Children

The extension is not directed at children and collects no personal information from anyone.

Changes

If a future version adds optional cloud voices, they will be opt-in and will be preceded by a separate disclosure before any text leaves your device. Any change to this policy will be published on this page with a new date.
