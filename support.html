Help

Support

Install, shortcuts, and the odd page that won’t read. Most questions are answered below.

Read Along is live on the Chrome Web Store. Version 1.1.1 is the current release and installs straight from the store.

Install

Install from the Chrome Web Store:

  1. Open the Read Along page on the Chrome Web Store.
  2. Click Add to Chrome. Brave uses the same button and the same store.
  3. Confirm the permissions prompt, then pin the icon from the extensions menu so the toolbar button is easy to find.

Add to Chrome

Read Along asks for access to the pages you read. That access is what lets it find the article text, paint the spoken word, and scroll the page. It does not modify the page or send text anywhere.

Troubleshooting

Nothing happens when I press the shortcut

First check that the page is a normal web page. Browser pages (brave://, chrome://, edge://), the built-in PDF viewer, and pages that draw text into a canvas — including Google Docs — cannot be read.

If the page is normal, make sure Read Along is enabled in the extensions menu, then reload the page. Another app may also be using the same shortcut; change it at the shortcuts page linked above.

There is no sound

Check the system volume and output device first. Then open the voice menu in the playback bar and pick a different voice. Some system voices are listed but not actually downloaded; install or download the voice in your operating system’s speech settings, then reload the page.

It reads in the wrong language or voice

Auto uses the page’s detected language and picks a matching installed voice. If the page is tagged incorrectly, pick a voice manually from the bar. For a language with no installed voice, add one in your system settings first.

The highlight is missing

Highlighting uses the CSS Custom Highlight API, which is available in current Brave, Chrome, and Edge. If the highlight is missing on one particular site, the page may use shadow DOM or draw its text unusually. Try a regular article to confirm the extension is working, then send the URL so it can be investigated.

The page doesn’t scroll along

Auto-scroll only moves a page that actually has somewhere to scroll. If the whole article fits on screen, there is nothing to do. If you scroll manually, auto-scroll pauses for a few seconds instead of fighting you. Check the Scroll along switch in the bar, and make sure the reading pane — not just the outer window — is the thing that scrolls.

It starts in the wrong place

Read Along prefers the main article and ignores navigation, sidebars, and footers. On a cluttered page, start exactly where you want with ⌥-click, a selection, or Read from here in the right-click menu.

My settings reset after installing the store version

If you previously used an unpacked development build, the store version has a different extension ID, so preferences start fresh once. Set your speed and voice again and they will be remembered.

Known limits

  • Canvas text. Google Docs and some PDF viewers draw text into a canvas, so there are no text nodes to read.
  • Cross-origin iframes. Text inside an embedded frame from another site is not read.
  • Browser pages and the PDF viewer. Internal pages and the built-in PDF viewer are off limits to extensions.
  • Very long pages. They are read as one continuous stream; per-paragraph skipping is not available yet.
  • Protected content. Pages that deliberately block copying or speech may not work.
